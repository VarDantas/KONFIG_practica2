# Практическое задание №2. Инструмент визуализации графа зависимостей (Вариант 16)

## Общее описание
Инструмент для построения и визуализации графа зависимостей пакетов Ubuntu.
Реализован на Python. Этап 1: минимальный прототип с CLI-конфигурацией.

## Функции и настройки
- `parse_args()` — разбирает аргументы командной строки.
- `validate_args(args)` — проверяет корректность параметров.
- `print_config(args)` — выводит параметры в формате ключ: значение.

## Параметры командной строки
- `--package` — имя анализируемого пакета (обязательно).
- `--repo` — URL-адрес репозитория или путь к файлу (обязательно).
- `--mode` — режим работы: `url` или `file` (по умолчанию `url`).
- `--output` — имя сгенерированного файла с изображением (по умолчанию `graph.png`).
- `--depth` — максимальная глубина анализа зависимостей (по умолчанию 3).
