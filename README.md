Практическое задание №2. Инструмент визуализации графа зависимостей (Вариант 16)


Общее описание

Инструмент для построения, анализа и визуализации графа зависимостей пакетов Ubuntu (apt).
Реализован на Python. Не использует менеджеры пакетов (apt) и сторонние библиотеки для получения зависимостей.

Этап 1: Минимальный прототип с конфигурацией (CLI).
Этап 2: Сбор данных (парсинг Packages.gz из репозитория Ubuntu).
Этап 3: Основные операции (построение графа BFS с рекурсией, учет глубины и циклов).
Этап 4: Дополнительные операции (топологическая сортировка — порядок загрузки).
Этап 5: Визуализация (генерация D2, SVG и конвертация в PNG).


Функции и настройки (модули)

src/main.py
parse_args() — разбирает аргументы командной строки.
validate_args(args) — проверяет корректность параметров (например, глубина > 0).
print_config(args) — выводит параметры запуска.
main() — главная функция, управляет этапами.

src/parser.py
fetch_content(repo_url, mode) — скачивает URL или читает локальный файл, распаковывает gzip.
clean_dependency(dep) — очищает строку зависимости от версий (например, libc6 (>= 2.34) -> libc6).
parse_packages(text) — парсит текст Packages в словарь {пакет: [зависимости]}.
get_direct_dependencies(package, packages) — возвращает прямые зависимости пакета.

src/graph.py
recursive_bfs(...) — рекурсивный обход графа в ширину (BFS).
build_graph(root, packages, max_depth) — строит граф с учетом глубины и возвращает список связей.
load_test_graph(file_path) — загружает граф из тестового файла формата A: B, C.

src/load_order.py
topological_sort(graph) — выполняет топологическую сортировку (алгоритм Кана), возвращает порядок загрузки или None при цикле.

src/viz.py
generate_d2_code(edges) — генерирует текст на языке D2.
save_d2_and_render(d2_code, output_png) — сохраняет D2, генерирует SVG через утилиту d2 и конвертирует SVG в PNG через rsvg-convert.


Параметры командной строки

--package — имя анализируемого пакета (обязательно).
--repo    — URL-адрес репозитория Packages.gz или путь к локальному файлу (обязательно).
--mode    — режим работы: url (по умолчанию) или file (тестовый режим).
--output  — имя выходного PNG-файла (по умолчанию graph.png).
--depth   — максимальная глубина анализа зависимостей (по умолчанию 3).


Команды для сборки, запуска и тестов

Запуск с реальным репозиторием Ubuntu:
./run.sh --package jq --repo http://archive.ubuntu.com/ubuntu/dists/jammy/main/binary-amd64/Packages.gz --mode url

Запуск в тестовом режиме (чтение графа из файла):
./run.sh --package A --repo data/test_graph.txt --mode file --depth 3 --output graph_test.png


Примеры использования

Тестовый режим (пакеты A, B, C, D):

    Параметры запуска:
    package: A
    repo: data/test_graph.txt
    mode: file
    output: graph_test.png
    depth: 3

    Порядок загрузки:
    1. D
    2. B
    3. C
    4. A

    Результат (список зависимостей):
    A -> B
    B -> D
    A -> C
    C -> D

    Визуализация:
    D2-код сохранён в graph_test.d2
    SVG-файл сохранён в graph_test.svg
    Изображение сохранено в graph_test.png

Обработка ошибок:
    --depth -1       -> Ошибка: глубина анализа должна быть больше 0
    несуществующий пакет -> Пакет 'xyz' не найден в репозитории
    цикл в графе     -> В графе обнаружен цикл! Порядок загрузки определить невозможно.


Зависимости

Для работы визуализации требуются утилиты:
- d2 (язык диаграмм) — генерирует SVG.
- librsvg2-bin (rsvg-convert) — конвертирует SVG в PNG.

Установка:
sudo apt install librsvg2-bin
(и d2 согласно инструкции с d2lang.com)
